# Reference images

The four `ChatGPT Image Aug 11, 2026, 06_14_14 AM*.png` files in the project root are concept references only. They informed the warm olive-and-orange visual direction, content hierarchy, large blanket workspace, square library, and project insights presentation.

They are not application assets and are not copied, cropped, bundled, or displayed by SquareTool. All granny square previews and blanket layouts are rendered programmatically. Where the concepts conflict with the product specification, the specification is authoritative: phone layouts use five consistent navigation destinations, two square columns, stacked insights, calculated values, and local file sharing rather than public links.
